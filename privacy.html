Privacy Policy — Arka Content Pipeline

Last updated: 27 October 2026

Arka Content Pipeline (“the application”) is a private, single-user tool operated by Sakti (saktiweb1@gmail.com). It uses Google OAuth to access data belonging to that same account only. There are no other users, no public accounts, and no third-party recipients of Google user data.

1. Google user data accessed

Google API scopeWhy it is needed
Google SheetsRead and update the content-bank spreadsheet that tracks content ideas, scripts, captions and publishing status.
Google DriveUpload rendered image assets (PNG/SVG carousel slides) into a folder the account holder owns, and read back the folder listing.
Google DocsRead the brand-guideline document the account holder wrote, so generated drafts follow his own writing rules.
Google CalendarRead upcoming events to pick publishing slots.
Google TasksRead the account holder’s task list as a secondary source of pending work items.
Gmail (modify)Read notification emails that the account holder already receives (for example scheduling confirmations) and apply labels so they are not processed twice. The application does not send email on the account holder’s behalf.
OpenID Connect (email / profile)Identify which account is authorizing the application.

2. How the data is used

  • Data is used strictly to perform the content-production tasks listed above.
  • No data is sold, rented, or shared with advertisers or any third party.
  • No Google user data is used to train machine-learning models.
  • No human other than the account holder reads the data.

3. Storage and retention

The application runs on a single private server controlled by the account holder. OAuth credentials are stored locally on that server with file permissions limited to the account holder (0600). The application keeps only:

  • the OAuth refresh token, and
  • a local copy of the content-bank data needed to render and schedule posts.

Data is retained only while the tool is in use. Deleting the stored credentials stops all access immediately.

4. Revoking access and deleting data

Access can be revoked at any time at myaccount.google.com/permissions. Once revoked, the application can no longer read or write any Google data. To request deletion of the locally stored copy, email saktiweb1@gmail.com; deletion is performed within 7 days.

5. Limited Use disclosure

Arka Content Pipeline’s use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

6. Changes

If the data practices change, this page is updated and the “last updated” date above is revised.
